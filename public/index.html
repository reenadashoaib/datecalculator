How the count works

The calculator counts the days from the start date up to the end date. The start date is counted and the end date is not, the same way you would count nights in a hotel: Monday to Wednesday is 2 days. Tick Count the end date too if you want both dates included, for example when counting the days of an event that runs Monday to Wednesday (3 days).

Months and years are counted by calendar, not by averaging 30 or 365 days. From January 15 to March 15 is exactly 2 months, even though February is short. When a start date falls on a day that a later month doesn’t have, such as the 31st, the month ends on that month’s last day.

Leap years are handled automatically. The count is done on calendar dates rather than clock time, so daylight saving changes never add or remove a day.

Common uses

  • Days left until a deadline, holiday, wedding or due date
  • How long ago something happened, like a move or a start date at work
  • Notice periods, rental terms and subscription lengths
  • Counting a streak, a trip or the length of a project

Questions

How many days are there between two dates?

Enter both dates above. The large number is the count of days from the start date up to the end date. The table under it breaks the same span into years, months, weeks, hours and minutes.

Does the result include the end date?

Not by default. Tick “Count the end date too” to add it. That adds exactly one day to the total.

Can I count backwards to a date in the past?

Yes. If the end date is before the start date, the calculator shows how many days apart they are and tells you the dates were entered in reverse.

How are workdays counted?

Workdays are Monday to Friday. Public holidays are not removed, because they differ by country. Use the workdays calculator for more detail.

Can I share a result?

Yes. The page address updates as you change the dates, so “Copy link to this result” gives a link that opens the same calculation.
